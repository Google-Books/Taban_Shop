# پوشاک تابان — فروشگاه نمونه

سایت به‌صورت کامل استاتیک (HTML/CSS/JS ساده) ساخته شده و به هیچ سرور یا بیلد خاصی نیاز ندارد.

## ساختار فایل‌ها
```
taban-shop/
├── index.html          صفحه اصلی (تنها فایل HTML — همه صفحات با جاوااسکریپت داخل آن رندر می‌شوند)
├── css/style.css        استایل کامل سایت (تم تیره + روشن)
├── js/data.js            داده‌های اولیه دسته‌بندی‌ها و لینک تصاویر محصولات
└── js/app.js             منطق کامل برنامه (مسیریابی، پنل مدیریت، گفتگو، تم و...)
```

## چطور در گیت‌هاب آپلود کنم؟ (بدون نیاز به خط فرمان)

1. وارد حساب گیت‌هاب خود شوید و یک ریپازیتوری جدید بسازید (مثلاً با نام `taban-shop`).
2. داخل صفحه ریپازیتوری روی گزینه **Add file → Upload files** بزنید.
3. تمام فایل‌ها و پوشه‌های داخل `taban-shop` (یعنی `index.html`، پوشه `css` و پوشه `js`) را با حفظ همین ساختار داخل آن بکشید و رها کنید (Drag & Drop).
4. پایین صفحه دکمه سبز **Commit changes** را بزنید.
5. برای اینکه سایت به‌صورت زنده و با یک لینک باز شود:
   - به بخش **Settings → Pages** ریپازیتوری بروید.
   - در قسمت **Branch** گزینه `main` و پوشه `/root` را انتخاب کرده و **Save** بزنید.
   - بعد از حدود یک دقیقه، آدرس سایت شما به شکل زیر در همان صفحه نمایش داده می‌شود:
     `https://USERNAME.github.io/taban-shop/`

## نکات مهم درباره این نسخه نمونه

- **ذخیره‌سازی:** طبق درخواست شما، این نسخه هنوز به دیتابیس یا سرور وصل نیست. تمام تغییرات پنل مدیریت (قیمت، تخفیف، ترتیب محصولات، افزودن/حذف) فقط در همان مرورگر Chrome ذخیره می‌شود (`localStorage`) تا بتوانید دموی کامل را نمایش دهید.
- **ورود به پنل مدیریت:** از دکمه منو (بالا-راست) → گزینه «ثبت‌نام» → به‌جای ایمیل، کد `0785993080` را وارد کنید.
- **جابه‌جایی با Drag & Drop:** روی موس/دسکتاپ (Chrome) کاملاً کار می‌کند. روی گوشی، به‌جای درگ‌ودراپ می‌توانید محصول را با فشار طولانی حذف و دوباره اضافه کنید، یا برای دمو از لپ‌تاپ استفاده کنید.
- **دسته «کت شلوار»:** برای این دسته هیچ لینک تصویری در پیام شما نبود، بنابراین فعلاً خالی است و پیام «به‌زودی» نشان داده می‌شود. از همان پنل مدیریت (دکمه «افزودن محصول») می‌توانید محصولات این دسته را اضافه کنید.
- **کیفیت تصاویر:** لینک‌هایی که ارسال کردید، تصاویر بندانگشتی (thumbnail) گوگل هستند و کیفیت پایینی دارند. برای نسخه نهایی و حرفه‌ای پیشنهاد می‌شود تصاویر با کیفیت اصلی (حداقل ۸۰۰ در ۱۰۰۰ پیکسل) جایگزین شوند.
- **صفحه گفتگو:** یک شبیه‌سازی ساده از چت است (بدون سرور واقعی) تا تجربه خرید را نشان دهد؛ پیام‌ها فقط در همان مرورگر ذخیره می‌شوند.

## قابلیت‌هایی که علاوه بر درخواست شما اضافه شد
- نشان تخفیف قابل تنظیم از ۱۰٪ تا ۸۰٪ روی هر محصول (در پنل مدیریت) با نمایش خودکار قیمت قبل/بعد از تخفیف.
- تم روشن/تیره با انتقال نرم و دکمه در همه صفحات.
- پیام خوش‌آمد و افکت «درخشش» طلایی روی شعار سایت در splash screen.
- صفحه خالیِ زیبا برای دسته‌بندی‌هایی که هنوز محصولی ندارند (به‌جای نمایش خالی/خراب).
